## Project Overview

This project is a **modular Python ETL pipeline** for processing healthcare-related CSV data.  
It demonstrates **real-world data engineering skills**, including:

- Data extraction, transformation, and loading (ETL)
- Data validation and cleaning
- Logging and error handling
- Scalable project structure
- Cloud-ready design (Azure-compatible)

The project is designed to be **interview-ready** for **Python Data Engineer** roles.

## Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/sajidprofessional/python-etl-pipeline.git
cd python-etl-pipeline

2. Create a virtual environment
python -m venv venv
source venv/Scripts/activate   # Windows
3. Install dependencies:
pip install -r requirements.txt

How to Run
Run manually:
py -m etl.main
Run with Windows Task Scheduler:
I.Create a .bat file:
@echo off
cd C:\ETL_pipeline_in_python\python-etl-pipeline
py -m etl.main
pause
II.Schedule it daily/hourly as needed.

Logging

All ETL actions are logged in logs/etl.log:
