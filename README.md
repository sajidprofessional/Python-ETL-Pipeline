# Python ETL Pipeline

An end-to-end ETL pipeline built using Python to demonstrate real-world data engineering practices including data validation, error handling, logging, and scheduling readiness.

## Features
- Extracts CSV data
- Transforms and cleans healthcare-style records
- Validates schema and null values
- Loads processed data to output storage
- Logging and exception handling
- Scheduler-ready (Windows Task Scheduler / Airflow-ready design)

## Tech Stack
- Python 3.10+
- Pandas
- Logging
- SQL-ready design
- Windows Task Scheduler compatible
